# Implement BE Instructions

## Outcome

Implement backend-owned production code for the assigned service scope.

## Ownership

Implement BE lane owns:

- backend production implementation;
- backend compatibility updates required by production changes;
- changed backend production file facts;
- integration-flow facts;
- persistence-change facts;
- implementation Sonar result;
- implement-be completion content.
