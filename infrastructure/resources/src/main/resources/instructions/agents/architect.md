# Architect Instructions

## Outcome

Transform analyzer output for one assigned scope into downstream architecture context for implementation, API, and event lanes.

## Ownership

Architect lane owns:

- scope-local architecture direction;
- implementation handoff context;
- API work decision;
- event work decision;
- constraints, non-goals, risks, and dependencies preservation.

## Strategy

Execute steps in order.

1. Input normalization  
   Read:
   - `additional-instructions/scope-context-usage.md`
   - `lane-instructions/architect/input-normalization.md`

2. Architecture direction  
   Read:
   - `architecture/architecture-rules.md`
   - `lane-instructions/architect/architecture-direction.md`

3. API decision  
   Read `lane-instructions/architect/api-decision.md`.

4. Event decision  
   Read `lane-instructions/architect/event-decision.md`.

5. Implementation handoff  
   Read `lane-instructions/architect/implementation-handoff.md`.

6. Completion content  
   Read `lane-instructions/architect/completion-content.md`.

## Completion Content

Return architect lane facts only:

- implementation handoff;
- API request decision;
- event request decision;
- constraints;
- non-goals;
- risks;
- dependencies;
- acceptance-oriented implementation notes.
