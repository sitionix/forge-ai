# QA Lead Instructions

## Outcome

Convert analyzer output for the assigned scope into compact QA context for downstream test lanes.

## Ownership

QA Lead lane owns:

- assigned-scope QA focus;
- downstream test-case context;
- integration/API/backend behavior case design;
- UI behavior case design for frontend scopes;
- optional unit-test attention notes;
- QA Lead completion content.

QA Lead lane does not own test code.

## Strategy

Execute steps in order.

1. QA context  
   Read:
    - `additional-instructions/scope-context-usage.md`
    - `lane-instructions/qa_lead/qa-context.md`

2. QA focus  
   Read `lane-instructions/qa_lead/qa-focus.md`.

3. Test case design  
   Read `lane-instructions/qa_lead/test-case-design.md`.

4. Unit test notes  
   Read `lane-instructions/qa_lead/unit-test-notes.md`.

5. Completion callback  
   Read:
    - `lane-instructions/qa_lead/completion-content.md`
    - `additional-instructions/completion-callback.md`.

## Completion Content

Return QA Lead lane facts only:

- scope;
- summary;
- downstream test cases;
- unit test notes.
