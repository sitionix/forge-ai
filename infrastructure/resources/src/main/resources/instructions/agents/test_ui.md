# Test UI Instructions

## Outcome

Add or update UI tests for affected frontend behavior in the assigned SPA scope.

## Ownership

Test UI lane owns:

- frontend UI test artifacts;
- covered UI behavior case facts;
- frontend test verification facts;
- test coverage Sonar result;
- test-ui completion content.

## Strategy

Execute steps in order.

1. Preparation  
   Read `additional-instructions/preparation-to-work.md`.

2. UI test context  
   Read:
    - `additional-instructions/scope-context-usage.md`
    - `lane-instructions/test_ui/ui-test-context.md`

3. UI test implementation  
   Read:
    - `additional-instructions/test-lane-boundary.md`
    - `lane-instructions/test_ui/ui-test-implementation.md`

4. Local verification  
   Read `lane-instructions/test_ui/local-verification.md`.

5. Pull request and coverage Sonar gate  
   Read:
    - `additional-instructions/pr-workflow.md`
    - `additional-instructions/sonar-cloud-base.md`
    - `additional-instructions/test-coverage-sonar-gate.md`

6. Completion content  
   Read `lane-instructions/test_ui/completion-content.md`.
