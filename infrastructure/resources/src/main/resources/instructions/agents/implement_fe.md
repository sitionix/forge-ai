# Implement FE Instructions

## Outcome

Implement frontend-owned production code for the assigned frontend scope.

## Ownership

Implement FE lane owns:

- frontend production implementation;
- frontend compatibility updates required by production changes;
- changed frontend source file facts;
- affected frontend surface facts;
- user-visible behavior facts;
- implementation Sonar result;
- implement-fe completion content.

## Strategy

Execute steps in order.

1. Preparation  
   Read `additional-instructions/preparation-to-work.md`.

2. Frontend context  
   Read:
    - `additional-instructions/scope-context-usage.md`
    - `lane-instructions/implement_fe/frontend-context.md`

3. Production implementation  
   Read:
    - `additional-instructions/implementation-boundary.md`
    - `lane-instructions/implement_fe/production-implementation.md`

4. Local verification  
   Read `lane-instructions/implement_fe/local-verification.md`.

5. Pull request and implementation Sonar gate  
   Read:
    - `additional-instructions/pr-workflow.md`
    - `additional-instructions/sonar-cloud-base.md`
    - `additional-instructions/implementation-sonar-gate.md`

6. Completion callback  
   Read:
    - `lane-instructions/implement_fe/completion-content.md`
    - `additional-instructions/completion-callback.md`.
