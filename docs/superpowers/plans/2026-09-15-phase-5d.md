# Phase 5D — Reset Context Implementation Plan

**Goal:** Explicitly retire an idle reusable context; the normal next allocation starts a new session and provider conversation.

**Spec:** User-provided Phase 5D task in this conversation is authoritative.

**Architecture:** Nullable `context_reset_at`; reusable uniqueness and lookup exclude retired sessions. Reset and allocation share the existing transaction advisory scope lock, acquired before the session row lock to avoid inverted lock order. Reset only updates the retirement marker. Backend returns eligibility and authoritative context truth; Nexus proxies it; Console applies command success before refreshing.

**Constraints:** Preserve turns, events, provider identifiers, workflow policy, lineage, routing, leases and Phase 5A–5C semantics. No provider calls during Reset. No replacement until allocation.
