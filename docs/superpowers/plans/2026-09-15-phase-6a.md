## Design

Persist contextGroupKey on Node, RunNode and NodeRun, and contextIterationId on NodeRun/session. Resolve identity from the exact delivered contributions before creating an activation. Filter source runs by workflow, group and repository; zero identities starts a UUID, one propagates, multiple throw AGENT_CONTEXT_ITERATION_CONFLICT. Frames never define identity. Retry and every NodeRun copy preserve both fields.

Reuse the existing allocator, scope advisory lock, row locks, leases and provider path. Add mode and iteration to reusable lookup and partial unique indexes; keep reset exclusion. Existing broader scope lock safely serializes Reset and allocation across iterations. Both reusable modes support Reset/Resume.
