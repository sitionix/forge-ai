# MCP Stage 5 Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settings → Integrations displays saved global MCP connections and supports Custom HTTP create/test/permissions/enable/edit/disable/remove through typed Nexus.

**Architecture:** Console uses its existing page router, native dialogs and request coordinator. A focused MCP API calls existing Nexus connection routes; a narrow canonical session facade delegates combined-mode authentication to the accepted Remote Access owner. Agent persistence, probe, approval, revocation and execution boundaries remain authoritative.

**Tech Stack:** Existing JavaScript ES modules, declaration files, Vitest/JSDOM, Vite, Chrome smoke script; Spring Boot 3.3.4, Java 21, Maven, ForgeIT and existing local MCP/Codex fixtures. No new product dependency.

**Spec:** [2026-09-28-mcp-stage-5-design.md](../specs/2026-09-28-mcp-stage-5-design.md).

## Global Constraints

- Regular `feature/SITIONIX-152` branch based on merged main `0ecef203`; no worktree, personal configuration, production secret, provisioning or sandbox-network changes.
- Global Settings navigation, independent of project selection; existing English Console styling and current router.
- Reuse existing MCP CRUD/probe/inventory/approvals/enabled/delete and typed map → execute → map; no catalog, OAuth, schema or runtime redesign.
- New connections are disabled and have no approved tools; initial project policy is `SELECTED` with no projects.
- Keep secrets out of URL, storage, rendered metadata, error objects and logs. Credential values are write-only; CSRF stays in private memory.
- No automatic mutation retry. Reconcile ambiguous operations, preserve server-confirmed state, invalidate stale UI ownership on cancellation/navigation.
- Connected partial MCP inventory and root-systemd isolation retain Stage 4 contracts; historical OS probes are not rerun claims.
- Milestone A requires a real normal Agent tool call and revoke proof; explicitly mark unavailable deployment boundaries `NOT_VERIFIED`.

## Review Focus

- Save may persist before its response is lost: never replay create automatically; reconcile saved metadata and require an explicit decision (Tasks 2/4).
- A probe can return 401 for external MCP auth while operator session remains valid: retain the session and offer credentials (Tasks 2/4).
- Existing Remote Access login must authorize Settings with the same session; logout/expiry revokes both feature audiences (Task 1).
- Endpoint/auth changes invalidate approvals; stale UI selections cannot restore a changed schema fingerprint (Task 4).
- A late secret-bearing response after cancel/BFCache must not restore a form, secret, CSRF or old page state (Tasks 2/3/4).
