# Java Style Basics

## Purpose

Reusable Java style rules for implementation and test code.

## Rules

- Prefer explicit types; do not use `var`.
- Use `final` for local variables whenever possible.
- Do not use fully qualified class names; import classes and use short names.
- Use `this.` for instance field and instance method access.
- Keep control flow explicit and simple.
- Avoid unnecessary abstraction, hidden behavior, and magic fallbacks.
