# Test Unit Generated Artifact Rules

Read this file only when affected code/tests use generated DTOs, clients, API/event contract types, or generated producer/consumer artifacts.

- Use already-provided generated types.
- Do not generate contracts from this lane.
- Do not create replacement DTOs or ad-hoc contract shapes.
- Do not invent fields, endpoint paths, payloads, topics, enum values, or artifact coordinates.
- If required generated artifacts are missing or incompatible, keep exact evidence for completion content.
